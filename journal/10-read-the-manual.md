# Phase 10: read the manual

**The lesson.** I spent an hour pushing every block in a room from every side, looking for a
staircase that was never there. The person watching said the obvious thing: this is looked up,
not discovered. He was right, and it was not the first time. The raft is not behind a block in
the north wing. It is in a basement under the southwest rooms, reached by the stairs on the east
side of a room with eight Darknuts, which you do not fight. The map site's convention had misled
me, and a two-line search would have settled it in a minute.

**Why the bot could not read the guides.** The tool I use to fetch web pages is blocked by
almost every walkthrough site. This session has a real browser available, and those sites don't
block a browser. So the bot now has the actual documents: a full speedrun walkthrough of the
whole game from 2005, with the route and the trick for every dungeon and boss, and a
room-by-room walkthrough of Levels 3 and 4. They live in the knowledge folder, and the rule in
the plan is now: research first, experiment second. The emulator confirms facts and finds the
fastest execution; it does not rediscover what the community wrote down twenty years ago.

**What the guides changed immediately.**
- Level 3's real fast route, including the corridor Keese that refill bombs before the gauntlet.
- Bombs work on Darknuts. The five-Darknut room is a bomb room, not a sword duel, and the run
  keeps at least four for it.
- The eight-Darknut room is a dash to the stairs, not a clear.
- Level 4, before the bot has set foot in it: the key order, the ladder's secret passage, the dark
  rooms to navigate from memory, the block that opens Gleeok's door, and four hits per head.

**Also from the person watching, both true and both now in the code.** Standing still is never
progress: detour, or kill what is in the way. And at full hearts the sword fires a beam, so a
clean run is also a faster run, because the bot can kill from range.
